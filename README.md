# 仕事用ダッシュボード（Google Apps Script 版）

Google Apps Script（GAS）のウェブアプリとして動くダッシュボードです。
PC へのインストールや Google Cloud の設定は不要で、ブラウザでウェブアプリの URL を開いて使います
（チャット機能のみ例外。後述）。

| 機能 | 内容 | 使う機能 |
| --- | --- | --- |
| 時計・残業時間 | 現在時刻、出退勤時刻、本日の勤務・残業時間、今月の残業合計 | （GAS 内に保存） |
| カレンダー | 月表示カレンダー（タスク期限日に印）、今日の予定 | CalendarApp |
| タスク | 今日のタスク（期限切れを含む）の追加・完了・削除 | （GAS 内に保存） |
| メール | 今日の受信メール数、未読メール数 | GmailApp |
| チャット | Google Chat の未読メッセージ数（合計とスペースごと） | Chat 拡張サービス |
| Redmine | 自分が担当の未完了チケットのうち、期日が近いもの・期限切れのもの | UrlFetchApp |
| ショートカット | URL のリンク、フォルダのパスのコピー | （GAS 内に保存） |

## 設置方法

### 1. プロジェクトを作る

1. https://script.google.com/ で「新しいプロジェクト」を作成し、名前を付ける（例: Work Dashboard）
2. 左の「プロジェクトの設定」（歯車）で **「appsscript.json」マニフェスト ファイルをエディタで表示する** をオンにする
3. `gas/` フォルダの各ファイルを、同じ名前でエディタに作成して内容を貼り付ける

   | このリポジトリ | エディタでの作成方法 |
   | --- | --- |
   | `appsscript.json` | 既存のファイルを上書き |
   | `Code.gs`, `Config.gs` | 「＋ → スクリプト」で `Code`, `Config` を作成（最初からある `コード.gs` は `Code` に名前を変えて上書き） |
   | `index.html`, `style.html`, `app.html` | 「＋ → HTML」で `index`, `style`, `app` を作成 |

   [clasp](https://github.com/google/clasp) を使う場合は `gas/` を rootDir にして `clasp push` でも構いません。

### 2. 設定する

- `Config.gs` の `CONFIG` を編集します（勤務時間、Redmine の URL など）
- Redmine の API キーは「プロジェクトの設定 → スクリプト プロパティ」に、
  プロパティ `REDMINE_API_KEY`、値に API キーを追加します（コードに書かないため）

### 3. デプロイする

1. 右上の「デプロイ → 新しいデプロイ」で種類「ウェブアプリ」を選ぶ
2. 「次のユーザーとして実行: 自分」「アクセスできるユーザー: 自分のみ」でデプロイ
   （`appsscript.json` にもこの設定を書いてあります）
3. 初回は権限の確認画面が出るので、自分のアカウントで許可する
4. 表示された「ウェブアプリ URL」をブラウザのブックマークやホームページに登録する

コードを変更したときは「デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン」で更新すると、同じ URL のまま反映されます。

## 各機能の詳細

### 時計・残業時間

`Config.gs` の `work`（初期値: 9:00〜17:30、休憩 60 分）で計算します。

- 所定労働時間 = 終業 − 始業 − 休憩（初期値では 7 時間 30 分）
- 勤務時間 = 退勤 − 出勤 − 休憩（休憩は勤務開始時点から差し引きます）
- 残業時間 = 勤務時間 − 所定労働時間（マイナスは 0）。9:00 出勤なら 17:30 を過ぎた分が残業です
- 退勤前は現在時刻で計算し、1 分ごとに更新します
- `autoClockIn: true` のときは、その日に初めてダッシュボードを開いた時刻を出勤として記録します。
  出退勤時刻は画面上で修正できます
- 今月の残業が 30 時間以上で黄色、45 時間（36 協定の原則的な月の上限）以上で赤色になります
- 休憩時間が 60 分でない場合は `breakMinutes` を変更してください

### メール（GmailApp）

- 今日の受信: 今日 0 時以降に届いたメールの数。自分が送ったメール・下書き・チャットは除き、アーカイブ済みは含みます
- 未読: 受信トレイの未読メール数（スレッド数ではなくメール数）
- 数えるのは最大 `mail.maxThreads`（既定 500）スレッドまでで、超えると「+」を付けます

### チャット（Chat 拡張サービス）

- 各スペース・DM について、自分の既読位置より後に投稿されたメッセージを未読として数えます
  （スレッド内の返信も含みます。1 スペース 99 件を超えると「99+」）
- 調べるのは最近動きのあったスペースから `chat.maxSpaces` 件（既定 30）です
- DM はスペース名が取得できないため「ダイレクト メッセージ」と表示します。名前をクリックすると Google Chat を開きます
- Google Chat アプリ上の未読表示とは数え方が一致しない場合があります（例: ミュートしたスペースも数えます）

**注意:** Google Chat API は Google Workspace（会社・学校）のアカウントで使える API で、
Google のドキュメントでは Chat API の構成（Google Cloud での設定）が必要とされています。
そのため Google Cloud を使えない環境では、チャットのカードにエラーが表示される可能性があります。
その場合は `Config.gs` の `chat.enabled` を `false` にしてください。

#### Chat API を使うための設定（Google Cloud が使える場合）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作成し、ダッシュボードのトップに表示される「プロジェクト番号」を控える
2. 「API とサービス → OAuth 同意画面」を設定する（会社の Workspace アカウントならユーザーの種類は「内部」）
3. 「API とサービス → ライブラリ」で **Google Chat API** を有効にする
4. Google Chat API の「構成」画面で、アプリ名・アバター URL・説明を入力して保存する
   （ダッシュボードはこのアプリを使いません。Chat API を呼ぶための登録です）
5. GAS エディタの「プロジェクトの設定 → Google Cloud Platform（GCP）プロジェクト → プロジェクトを変更」で、手順 1 のプロジェクト番号を設定する
6. ウェブアプリを開き直し、権限の確認画面が出たら許可する

うまくいかない場合は、チャットのカードに表示されるエラー文を確認してください。
会社の Workspace では、管理者が Google Cloud プロジェクトの作成や Chat API の利用を制限していることがあります。
あわせて `appsscript.json` の `enabledAdvancedServices` と `chat.*` の権限を削除すると、初回の許可画面から Chat の項目がなくなります。

### Redmine（UrlFetchApp）

- GAS は Google のサーバーから Redmine にアクセスするため、Redmine がインターネットから https で接続できる必要があります。
  接続元の IP アドレスを制限している場合は、Google のサーバーからの接続が拒否されることがあります
- Redmine の「管理 → 設定 → API」で REST API を有効にし、個人設定画面の「API アクセスキー」をスクリプト プロパティ `REDMINE_API_KEY` に設定します
- 取得条件: 担当者 = 自分、ステータス = 未完了、期日 ≦ 今日 + `daysAhead` 日（`includeOverdue: false` なら今日以降のみ）

### ショートカット

画面右下の ✎ から登録・削除・並べ替え（ドラッグ）ができます。

- URL: 新しいタブで開きます（Google ドライブのフォルダ、社内システムなど）
- フォルダ: ブラウザからは PC のフォルダを開けないため、クリックするとパスをコピーします。
  エクスプローラーのアドレス欄に貼り付けて開いてください

## データの保存先・権限

- 勤怠・タスク・ショートカットは、スクリプトの「ユーザー プロパティ」（Google アカウント内）に保存されます。
  完了から 30 日たったタスクは自動で削除します
- 要求する権限（`appsscript.json` の `oauthScopes`）
  - `https://mail.google.com/`: GmailApp でメールを検索・既読状態を確認するため。
    GmailApp はこの権限を必要とします（このダッシュボードはメールの送信・削除・変更はしません）
  - `calendar.readonly`: 予定の読み取り
  - `script.external_request`: Redmine への接続
  - `userinfo.email`: 自分が送ったメールを「今日の受信」から除くため、自分のアドレスを取得
  - `chat.spaces.readonly`, `chat.messages.readonly`, `chat.users.readstate.readonly`: チャットの未読数
- ウェブアプリは必ず「アクセスできるユーザー: 自分のみ」でデプロイしてください。
  他の人がアクセスできる設定にすると、あなたの権限でメールやチャットの件数などが見えてしまいます
